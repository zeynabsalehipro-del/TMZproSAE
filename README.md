✈️ Projet : Group Trip PlannerCe projet est réalisé dans le cadre de la SAE - Développement & Déploiement d'une Application Web RESTful Conteneurisée.1. Objectif Général et Contexte 🌍Group Trip Planner est une plateforme collaborative conçue pour simplifier l'organisation de voyages à plusieurs. Cette solution permet de :Centraliser l'itinéraire : Créer un voyage et y ajouter différentes étapes (hôtels, activités, restaurants).Gérer les participants : Inviter des amis à rejoindre un voyage pour un accès partagé au programme.Suivre le budget : Associer un plan budgétaire à chaque voyage pour surveiller les dépenses.2. Choix Techniques 🛠️Notre stack technique respecte les contraintes imposées par le sujet:Backend : Python avec le framework FastAPI (ou Flask).Base de données : PostgreSQL (Relationnelle).ORM : SQLAlchemy (obligatoire pour la persistance).Infrastructure : Conteneurisation via Docker et orchestration via Docker Compose.3. Modélisation de la Base de Données (ORM) 📊Nous implémentons les trois types de relations obligatoires:Type de RelationDescriptionOne-to-OneUn Voyage possède un seul Plan Budgétaire.One-to-ManyUn Voyage contient plusieurs Destinations (étapes).Many-to-ManyLes Utilisateurs participent à plusieurs Voyages.4. Livrables Attendus ✅Conformément aux exigences, le dépôt contient:[x] Code Source : Intégralité du backend Python.[x] Docker : Fichier docker-compose.yml fonctionnel.[x] Données : Script SQL d'importation pour les tests.[x] Documentation : Ce fichier README détaillant l'architecture et les routes.[x] Docker Hub : Image publiée sur Docker Hub.5. Répartition des Tâches 👥👤 Membre A : Gestion des Utilisateurs & InfrastructureBackend : API pour l'inscription et la connexion (Auth).Base de données : Relation Many-to-Many (Utilisateurs ↔ Voyages).Docker : Configuration du Dockerfile et de PostgreSQL.👤 Membre B : Gestion des Voyages & DestinationsBackend : Routes pour créer un voyage et ajouter des étapes.Base de données : Relation One-to-Many (Voyage → Destinations).DevOps : Publication sur Docker Hub et gestion des volumes.👤 Membre C : Gestion du Budget & QualitéBackend : API pour le suivi des dépenses.Base de données : Relation One-to-One (Voyage → Budget).Qualité : Configuration de Swagger, README final et préparation de la soutenance.
